# Lagos Life Helper

Independent English companion to the Lagos Life browser game at https://lagoslife.app/.

## Build

`node build.mjs` builds ten static pages and a browser-only calculator into `dist/`. No runtime dependencies. `SITE_URL` controls canonical URLs and sitemap; default is https://lagoslifehelper.com.

## Evidence

Reviewed 2026-10-11. Official terms identify Vatar as operator, browser addresses, 18+ eligibility and fictional Game Naira. Public help confirms needs, Phone → Jobs, Go to work and Go automatically. Public housing confirmation states each home pays rent Saturday. No logged-in playthrough or numbered release version verified. No fixed pay/rent presets.

The calculator uses player inputs for shift pay, shift count, rent, loan, routine costs, reserve, cash and immediate costs. It estimates weekly surplus and rounded-up break-even shifts. It performs no API calls and stores no input data.

## Deployment

Independent Git repository and Vercel project. GitHub: https://github.com/Lena186-ux/lagos-life-helper. Custom domain lagoslifehelper.com is purchased (Active, expiry 2027-10-11) and attached to this project. NameSilo DNS uses the exact Vercel-recommended apex A records and www CNAME.

GA4 and Microsoft Clarity are optional and consent-gated; no ads, affiliate links or game assets are included. Original CSS skyline art. Future monetization is an advertising experiment after traffic and ad account approval, not a promise of income.
